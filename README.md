# 보안 체험 부스 · 점수 연동

세 게임을 **서로 다른 기기 3대**에서 열어도, 참가자마다 점수가 하나의 Google 스프레드시트에 쌓입니다.
참가자는 부스마다 **같은 이름 + 숫자 4자리**를 입력하면 점수가 이어집니다. 총점은 **1000점**입니다.

| 부스 | 주소 | 연동 점수 |
|---|---|---|
| 암호를 풀어야 해요! | `/cipher/` | 게임 점수(500점 만점) × 0.8 → **최대 400점** |
| 열쇠 미션 | `/key/` | 성공한 단계 × 100 → **최대 300점** |
| OX 퀴즈 | `/ox/` | 맞힌 문제 × 100 → **최대 300점** |

같은 게임을 다시 하면 **가장 높은 점수만** 남습니다.

---

## 1단계 · Google 스프레드시트 서버 만들기 (5분)

1. Google 드라이브에서 **새 스프레드시트**를 만듭니다. (이름 예: `보안부스 점수`)
2. 메뉴 **확장 프로그램 → Apps Script** 를 누릅니다.
3. 원래 있던 코드를 모두 지우고 `apps-script/Code.gs` 파일 내용을 그대로 붙여 넣은 뒤 💾 저장합니다.
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 을 고릅니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포** → 권한 승인(내 계정 선택 → "고급" → "안전하지 않음으로 이동" → 허용).
6. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 을 복사합니다.
   - 브라우저 주소창에 붙여 넣어 열었을 때 `점수 서버가 작동 중입니다.` 가 보이면 성공입니다.

> ⚠ 학교 Google 계정은 "모든 사용자" 항목이 없을 수 있습니다. 그때는 **개인 Gmail 계정**으로 만들어 주세요.
> "OO학교 내 사용자만"으로 배포하면 학생·방문자 기기에서 저장되지 않습니다.

## 2단계 · 서버 주소 넣기

`score-link.js` 파일 위쪽의 이 줄에 복사한 주소를 붙여 넣습니다.

```js
var API_URL = window.SCORE_API_URL || 'https://script.google.com/macros/s/여기에_붙여넣기/exec';
```

## 3단계 · GitHub Pages 로 올리기

1. GitHub에서 새 저장소(Repository)를 만듭니다. **Public** 으로 만드세요.
2. **Add file → Upload files** 로 이 폴더의 파일과 폴더를 **구조 그대로** 올립니다.
   ```
   index.html        ← 부스 선택 화면
   score-link.js     ← 세 게임 공통 점수 연동 (서버 주소는 여기)
   cipher/           ← 암호 풀기 (index.html, script.js, style.css)
   key/              ← 열쇠 미션 (index.html, key-mission.js)
   ox/               ← OX 퀴즈 (index.html)
   apps-script/      ← 서버 코드 (Code.gs, 참고용)
   ```
3. 저장소 **Settings → Pages** → Branch: `main` / `/ (root)` → **Save**.
4. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 에 접속됩니다.

## 4단계 · 기기 3대에 하나씩 열기

- 기기 1: `https://내아이디.github.io/저장소이름/cipher/`
- 기기 2: `https://내아이디.github.io/저장소이름/key/`
- 기기 3: `https://내아이디.github.io/저장소이름/ox/`

## 운영 방법

- 화면에 **참가자 등록** 창이 뜨면 참가자가 이름과 숫자 4자리를 입력합니다.
- 게임이 끝나면 위쪽에 "○○님 ○○점 저장 · 현재 총점" 알림이 뜹니다.
- 오른쪽 아래 **👤 이름 · 🏆 총점** 배지를 누르면 게임별 점수가 보입니다.
- 참가자가 바뀔 때는 배지 → **다음 참가자 →** 를 누르세요. 화면이 처음으로 돌아가고 등록 창이 다시 뜹니다.
- 10분 동안 아무 조작이 없으면 자동으로 다음 참가자 화면이 됩니다. (`score-link.js` 의 `IDLE_MINUTES`)
- 와이파이가 잠깐 끊겨도 점수는 기기에 보관했다가 연결되면 자동으로 보냅니다. 배지에 `⏳1` 처럼 보이면 전송 대기 중입니다.

## 기록 확인

스프레드시트에 시트 두 개가 자동으로 생깁니다.

- **참가자 점수**: 한 사람당 한 줄 (게임별 최고 점수, 총점, 처음·마지막 기록 시각). 총점 열로 정렬하면 순위표가 됩니다.
- **플레이 기록**: 게임이 끝날 때마다 한 줄씩 쌓이는 전체 기록.

## 배점을 바꾸고 싶을 때

`score-link.js` 의 `GAMES` 와 `apps-script/Code.gs` 의 `GAMES` 에서 `max` 를 **둘 다** 같은 값으로 바꾸고,
Apps Script 는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** 로 다시 배포하세요. (주소는 그대로 유지됩니다)

## 참고

- 이름의 띄어쓰기는 무시합니다. (`홍 길동` = `홍길동`) 숫자 4자리가 다르면 다른 사람으로 저장됩니다.
- 체험활동용으로 단순하게 만든 구조라, 주소를 아는 사람이 일부러 점수를 조작하는 것까지 막지는 않습니다.
